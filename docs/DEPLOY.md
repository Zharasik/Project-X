# Деплой: Vercel + Neon + Vercel Blob (бесплатно)

| Что | Где | Бесплатный лимит |
|---|---|---|
| Приложение | Vercel, тариф Hobby | без засыпания, свой домен `*.vercel.app` |
| База PostgreSQL | Neon (через интеграцию Vercel) | 0.5 ГБ — хватит на годы для нескольких групп |
| Файлы работ студентов | Vercel Blob | 1 ГБ хранения |

Займёт ~10 минут. Нужен только аккаунт GitHub.

## 1. Импорт проекта

1. Зайдите на <https://vercel.com/signup> → **Continue with GitHub**.
2. **Add New… → Project** → выберите репозиторий `Project-X` → **Import**.
3. Framework определится сам (Next.js). Ничего не меняйте, но **пока не нажимайте Deploy** — сначала база (шаг 2). Если уже нажали и сборка упала — это нормально, продолжайте.

> Production-деплой Vercel делает из ветки по умолчанию репозитория. Код MVP лежит в ветке `claude/serene-cori-dneh74` — слейте её в `main` (или сделайте её веткой по умолчанию), иначе в Vercel: **Settings → Environments → Production → Branch**.

## 2. База данных (Neon)

1. В проекте Vercel: **Storage → Create Database → Neon (Serverless Postgres)** → регион ближе к вам (например, Frankfurt) → **Create** → **Connect** к проекту.
2. Vercel сам добавит переменные `DATABASE_URL` и `DATABASE_URL_UNPOOLED` — приложение использует именно их. Таблицы создадутся автоматически при сборке (`prisma migrate deploy` в `vercel-build`).

## 3. Хранилище файлов (Vercel Blob)

1. **Storage → Create Database → Blob** → тип доступа **Private** → **Create** → **Connect** к проекту.
2. Появится переменная `BLOB_READ_WRITE_TOKEN`. Если при создании выбрали **Public**, добавьте ещё переменную `BLOB_ACCESS` = `public`.

## 4. Переменные окружения

**Settings → Environment Variables**, добавьте:

| Имя | Значение |
|---|---|
| `SESSION_SECRET` | случайная строка ≥ 32 символов — например, вывод `openssl rand -base64 32` или любой генератор паролей на 40 символов |
| `APP_TIMEZONE` | `Asia/Almaty` (или ваш часовой пояс) — необязательно |

## 5. Деплой

**Deployments → … → Redeploy** (или Deploy, если ещё не запускали). Через 1–2 минуты сайт будет доступен по адресу вида `project-x-xxxx.vercel.app`.

## 6. Первый запуск

1. Откройте сайт → появится ссылка **«Создать аккаунт преподавателя»** (страница `/setup`).
2. Введите имя, email, пароль, название первой группы. Галочка «Добавить готовый курс Web Design» создаст 12 тем с лекциями, практикой, тестами и горячими клавишами.
3. Вы попадёте на страницу группы — там **код для регистрации**. Раздайте его студентам: они регистрируются на `/register`.

> `/setup` работает, только пока в базе нет ни одного преподавателя, поэтому сделайте этот шаг сразу после деплоя.

## Обновления

Каждый push в production-ветку деплоится автоматически; новые миграции применяются при сборке.

## Свой домен

**Settings → Domains → Add** — Vercel покажет, какую DNS-запись добавить у регистратора.

## Альтернатива: свой сервер

Без Blob приложение хранит файлы на диске (`UPLOAD_DIR`). На любом VPS с Node.js 20+ и PostgreSQL: задайте переменные из `.env.example`, затем `npm ci && npx prisma migrate deploy && npm run build && npm start`.
